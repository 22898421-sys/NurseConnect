# Custom domain setup

Only do this after the supervisor confirms the exact registered domain spelling.

Previously mentioned variants:
- `nurseconnetcare.com.au`
- `nurseconnectcare.com.au`

These are different domains. Do not guess.

After the exact domain is confirmed:
1. In GitHub repository → **Settings → Pages**.
2. Enter the approved custom domain.
3. GitHub will provide DNS instructions.
4. Update DNS at the domain registrar.
5. Wait for DNS verification.
6. Enable **Enforce HTTPS** when available.

Do not point the custom domain to GitHub until the supervisor approves the GitHub version.
