# GitHub Pages deployment — no Base44 subscription required

## Upload using the GitHub website

1. Create a repository named `nurseconnectcare-website`.
2. Extract `NurseConnectCare_GitHub_Ready.zip`.
3. In GitHub choose **Add file → Upload files**.
4. Drag all extracted files and folders into GitHub.
5. Commit to `main`.
6. Open **Settings → Pages**.
7. Source: **Deploy from a branch**.
8. Branch: **main**; folder: **/(root)**.
9. Click **Save**.

GitHub will create a direct URL. No Node/npm installation is needed for this version.

## Test before sharing

Test these separately:
- Home
- Services
- About
- How It Works
- Contact

- EIRENIX Care / Clinician Access → clinician login/signup URL
