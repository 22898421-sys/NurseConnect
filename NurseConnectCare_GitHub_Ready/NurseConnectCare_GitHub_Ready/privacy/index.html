Privacy

Privacy and secure care access.

This standalone public website is designed not to store patient clinical information.

The GitHub-hosted public website contains service information and links into the existing secure NurseConnectCare/EIRENIX Care environment. It should not be used as a database for patient records or sensitive health information.

Care requests

The Request Care pathway hands users to the supervisor-provided secure system. If a future EIRENIX API or booking endpoint is connected, the organisation should ensure its privacy notice, consent wording, access controls, retention rules and security requirements are reviewed before launch.

Clinician access

Clinician access is separate from the public website and opens the EIRENIX Care secure portal.

Before production launch: replace this general page with the organisation's approved privacy policy and legal wording.
